# cv-mmap-gui Headless CLI Test - Task Log

## Date: 2026-03-05

### Decision: Created Standalone CLI-Only Test Path

**Problem:** Full GUI build blocked by OpenSSL dependency in headless CI/dev environments.

**Solution:** Added standalone CLI verifier executable at `cv-mmap-gui/app/cvmmap-client/tests/`:
- `CMakeLists.txt` - Minimal CMake configuration (no external deps)
- `protocol_fixture_check.cpp` - Self-contained test harness with embedded fixtures

**Command to run:**
```bash
cmake -S app/cvmmap-client/tests -B build-headless-cli \
    && cmake --build build-headless-cli \
    && ./build-headless-cli/protocol_fixture_check
```

### Fixtures Covered

| Fixture | Status | Notes |
|---------|--------|-------|
| v1 valid | PASS | Backward compatibility |
| v2 left-only | PASS | Single-plane parsing |
| v2 left+depth | PASS | Two-plane parsing |
| malformed plane_count | PASS | Rejection of > MAX_PLANES |
| malformed zero_stride | PASS | Rejection of zero stride |
| malformed truncated | PASS | Rejection of undersized data |

**Results:** 9/9 tests pass, exit code 0 on success, non-zero on failure.

### Key Design Decisions

1. **Zero external dependencies** - Pure C++23, no OpenSSL/GUI libraries
2. **Embedded fixture data** - No file I/O dependencies
3. **Deterministic behavior** - No randomness, reproducible results
4. **Non-zero exit on failure** - CI-friendly return codes
5. **Concise pass/fail output** - Easy to parse logs
